# MindMitra — Hackathon Product Specification (Prototype)

## Product
MindMitra is an offline-first, privacy-preserving companion for people living with mild–moderate dementia, designed for direct elderly use with caregiver-supported onboarding. The prototype combines culturally familiar cognitive activities, reminiscence, daily reminders, local activity tracking and a controlled conversational assistant.

## Locked decisions
- UI language: English
- Conversational prototype languages: English + Assamese
- Primary user: older adult living with family/caregiver support
- Caregiver: configuration/onboarding, routines, approved memories, dashboard and reports
- Privacy: personal data remains on-device
- Offline target: core app, games, reminders, memories and progress must work without internet
- Platform: React PWA first; Android packaging with Capacitor later
- Hackathon scope: prototype, not a medical device or diagnostic system

## Cognitive design principles
1. Recognition over recall where possible.
2. One task per screen.
3. Large touch targets and readable typography.
4. No timer, lives, leaderboard or punitive failure states.
5. Gentle recovery after mistakes.
6. Audio/read-aloud support.
7. Familiar everyday activities instead of abstract puzzles only.
8. Cultural and autobiographical content is caregiver-approved.
9. Activity data is not interpreted as a clinical cognitive score.

## MVP games
- Let's Cook — sequencing familiar ingredients/steps.
- Market Day — find requested household/market objects.
- Market Money — simple everyday change calculation.
- Finish the Song — recognition/category choice; use only licensed/public-domain/approved audio.
- Complete the Saying — familiar phrase completion.
- Sort & Categorise — everyday object categorisation.

## Personalization
Caregiver can provide preferred name, language, occupation, hometown, favourite food, hobby and approved memories. Future versions can generate autobiographical games from this information, but generated content must remain grounded in caregiver-approved facts.

## Agent architecture
The prototype uses a local rule-based agent with controlled tools. The production architecture should keep the same tool boundary:
- get_profile
- get_preferences
- get_today_schedule
- get_next_reminder
- mark_reminder_complete
- get_approved_memories
- get_recent_activity
- recommend_game
- start_game
- save_game_result
- get_daily_summary

Caregiver-only actions:
- create/edit reminder
- add/remove approved memory
- generate report

Medication reminder times/doses must be caregiver-configured data, not generated by the language model.

## Privacy architecture
Prototype: browser localStorage, no application network calls. Production: encrypted IndexedDB/Dexie, local files/media, local speech and an on-device model where hardware permits. No cloud LLM should receive personal data under the no-data-leaves-device requirement.

## Android path
Keep the React frontend and package it with Capacitor for Android. Native Android scheduling/notification capabilities should be used for reliable reminders while keeping the same local data model.

## Caregiver/ASHA reporting
Dashboard shows engagement/activity, reminder completion and activity trends. Reports can be generated for caregivers/community health workers/ASHA workers. Reports must clearly state that they summarize app activity and are not medical or diagnostic assessments.

## Research basis
The design direction is informed by dementia cognitive-stimulation and reminiscence literature, including:
- Cochrane: Cognitive stimulation to improve cognitive functioning in people with dementia.
- NICE guideline NG97: Dementia assessment, management and support; includes cognitive stimulation and consideration of reminiscence therapy.
- WHO dementia guidance on cognitive/psychosocial interventions.
- Research on accessible touchscreen games and familiarity for people living with dementia.

For a real deployment, conduct user testing with older adults/caregivers, accessibility review, local-language cultural review and appropriate ethics/privacy review before making clinical claims.
